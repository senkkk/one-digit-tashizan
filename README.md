# たしざんのもり

ひとけたの かずどうしを たす、ほいくえん ねんちょうむけの かんたんな あぷりです。

## あそびかた

1. りんごの かずを かぞえます。
2. こたえを いれるか、したの かずを えらびます。
3. せいかいすると できた かずが ふえます。
4. 10もん できると、なかまが ひとり ふえます。
5. なんども あそんで、50にんの なかまで ずかんを うめます。

## ためしかた

そのまま `index.html` を ひらくと あそべます。

ろおかるさあばあで みる ときは、つぎを つかいます。

```sh
python3 -m http.server 8000
```

そのあと `http://localhost:8000` を ひらきます。
